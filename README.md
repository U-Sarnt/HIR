# HIR\n\n![Python](https://img.shields.io/badge/python-3.10%2B-blue?logo=python&logoColor=white)\n![Rust](https://img.shields.io/badge/rust-edition%202021-orange?logo=rust&logoColor=white)\n![Docker](https://img.shields.io/badge/docker-ready-2496ED?logo=docker&logoColor=white)\n\nHIR is a high-performance Python library with Rust extensions for computationally intensive operations.\n\nThe project uses [PyO3](https://pyo3.rs/) to expose Rust functions as native Python modules, combining the ergonomics of Python with the performance of compiled Rust code.\n\n## Architecture\n\n```\nhir/\n├── src/          # Python package source\n├── rust_ext/     # Rust extension module (PyO3)\n├── Dockerfile    # Container build\n├── Cargo.toml    # Rust workspace manifest\n└── pyproject.toml\n```\n\n## Requirements\n\n- Python 3.10+\n- Rust toolchain (`rustup` recommended)\n- Docker (optional, for containerized builds)\n\n## Getting started\n\n```bash\n# Install Rust if not present\ncurl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh\n\n# Create virtual environment\npython -m venv .venv\nsource .venv/bin/activate\n\n# Install in development mode (builds Rust extension)\npip install -e .\n```\n\n## Docker\n\n```bash\ndocker build -t hir .\ndocker run --rm hir\n```\n\n## Status\n\nThis project is currently in early development.
